Build a filter for getting data from a B2W Database

Instructions

A filter Rule is comprised of 3 elements: Filter By, Operator, and Value.

  • Filter By: The data column that is filterable for the given database table. For example: BusinessUnitUniqueName
  • Operator: The method used to match data in the database.
  • Value: The value to search with.

If the builder is not flexible enough for the needs of a particular request, simply check the Query Override button and edit the query yourself. The syntax used is OData Query Syntax.

Groups:

A filter group takes multiple filters and groups them together with a Join operator. This allows you to join multiple filters together. If there are multiple rules in a group, they will be joined together with the join operator and separated from other groups via parenthesis.

Example:

Imagine you need to find specific equipment in the system. You are looking for either a D6 Dozer in Business Unit A OR a Medium Excavator in Business Unit B.

  • Group 1: (Equipment Type = ' D6 Dozer' AND BusinessUnit = 'A')
  • Group 2: (Equipment Type = 'Meduiom Excavator' AND BusinessUnit = 'B')

By joining these two groups with an OR operator, the database knows exactly what combinations are acceptable. Without groups, the system might get confused and search for a machine that is simultaneously a Dozer and an Excavator.

Operator Legend

  • != Is not equal to
  • > Is greater than
  • >= Is greater than or equal to
  • < Is less than
  • <= Is less than or equal to
